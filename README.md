# Lumen — Minecraft Launcher

Настольный лаунчер Minecraft Java Edition с авторизацией через Ely.by. Интерфейс на русском, тёмная тема, каталог Modrinth и GitHub Releases, отдельная библиотека игровых сборок, быстрый выбор релиза, избранные серверы и автоматическая подготовка игровых файлов.

## Запуск

Требования: Node.js 22.12+ и npm. Для игры нужен интернет. Java лаунчер проверяет автоматически и при необходимости загружает подходящий runtime из официального манифеста Mojang.

```bash
npm install
npm run dev
```

Команда запускает Vite и настольное окно Electron. Для проверки только интерфейса в браузере:

```bash
npm run web
```

Браузерный предпросмотр не принимает пароль Ely.by и не запускает Minecraft. Это намеренно: учётные данные обрабатываются только в настольном приложении, а игровой процесс Java нельзя запустить из обычной вкладки браузера.

Проверки и production-сборка интерфейса:

```bash
npm run check
npm run build
```

Сборка Windows x64 установщика (на Windows) записывает файл в `release/`:

```bash
npm run build:win
```

В GitHub Actions настроена сборка установщика на Windows runner. Установщик пока не подписан сертификатом издателя, поэтому Windows SmartScreen может показать предупреждение.

## Возможности

- Вход в игровой профиль Ely.by, включая запрос кода TOTP при включённой двухфакторной защите.
- Обновление Ely.by-сессии перед запуском и выход с аннулированием токена.
- Загрузка официальных vanilla-релизов Minecraft, библиотек и ресурсов при первом запуске.
- Интеграция authlib-injector для Ely.by. JAR загружается с официального endpoint; SHA-256 сверяется с опубликованной контрольной суммой.
- Автоматический выбор Java, установка официального Mojang runtime при отсутствии подходящей версии.
- Настройки выделяемой памяти, размера окна, Java-пути и папки игры.
- Избранные серверы с быстрым подключением, поиск по версиям/серверам и журнал прогресса запуска.
- Поиск модов на Modrinth по версии Minecraft и Fabric/Forge/NeoForge/Quilt с автоматической установкой совместимой версии и обязательных зависимостей.
- Установка модлоадеров Fabric, Forge, NeoForge и Quilt в отдельные экземпляры Minecraft.
- Поиск сборок на Modrinth и в GitHub Releases. Поддерживаются `.mrpack` и ZIP-архивы, содержащие `modrinth.index.json`; произвольные ZIP без манифеста не устанавливаются.
- Изолированная библиотека сборок: у каждого профиля отдельные моды, конфигурации, сохранения и настройки, при этом общие библиотеки и игровые ресурсы Minecraft не дублируются.
- SHA-1/SHA-512 проверка файлов сборок и модов, ограничение размеров, HTTPS-загрузки с проверкой перенаправлений и защита от выхода путей за пределы папки экземпляра.
- Браузерный предпросмотр может искать проекты, но скачивание файлов, изменение профилей и запуск игры доступны только в настольном приложении.

## Ely.by и безопасность

Приложение обращается к официальному [Minecraft Authentication API Ely.by](https://docs.ely.by/en/minecraft-auth.html): `/auth/authenticate`, `/auth/refresh` и `/auth/invalidate` на `https://authserver.ely.by`. В этой версии реализован документированный игровой вход логин/пароль с поддержкой TOTP. Документация Ely.by рекомендует [OAuth 2.0](https://docs.ely.by/en/oauth.html) как более безопасный и удобный вариант; OAuth flow здесь пока не подключён, поскольку лаунчеру нужен зарегистрированный OAuth client ID.

Пароль передаётся из Electron main process напрямую в Ely.by по HTTPS и не записывается в настройки. В системном хранилище сохраняется только токен с профилем; файл хранилища шифруется через `safeStorage` Electron. Если системное шифрование недоступно, аккаунт остаётся активным только до закрытия приложения и не сохраняется на диск. Браузерный предпросмотр не отправляет введённые данные ни лаунчеру, ни Ely.by.

## Структура

- `src/` — интерфейс React/Vite.
- `electron/main.cjs` — Ely.by API, защищённое хранилище, загрузка Java/Minecraft, запуск игры и IPC-обработчики.
- `electron/content.cjs` — поиск Modrinth/GitHub, проверка и загрузка файлов, установка модов/модпаков и управление изолированными экземплярами.
- `electron/preload.cjs` — ограниченный IPC-мост между интерфейсом и Electron.
- `electron/undici-compat.cjs` — небольшой совместимый адаптер `throwOnError` для текущей версии XMCL installer и исправленного Undici.

Игровые JAR, runtime, экземпляры и данные аккаунтов не хранятся в репозитории: они устанавливаются в пользовательскую папку данных лаунчера. Установка сборок распаковывает только клиентские `overrides/` и `client-overrides/`; серверные файлы игнорируются.
